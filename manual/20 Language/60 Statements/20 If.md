# If

```jyro
# fragment
if condition then
    statements
elseif condition then
    statements
else
    statements
end
```

The conditions are evaluated in order, for truthiness, and the block of the first truthy condition runs. When no condition is truthy the `else` block runs, if present. `elseif` blocks and the `else` block are optional. `elseif` is one word; `else if` opens a nested `if` that needs its own `end`.

```jyro
# input: { "score": 85 }
var grade
if Input.score >= 90 then
    grade = "A"
elseif Input.score >= 80 then
    grade = "B"
else
    grade = "C"
end
Output.grade = grade
```

```json
{ "grade": "B" }
```

A condition may be any value; see [Booleans and Null](/docs/language/types-and-values/booleans-and-null) for the truthiness rules.

```jyro
# input: { "items": [], "name": "" }
var notes = []
if Input.items then
    notes = Append(notes, "items is truthy")
end
if Input.name then
    notes = Append(notes, "name is truthy")
end
if Input.missing then
    notes = Append(notes, "missing is truthy")
end
Output.notes = notes
```

```json
{ "notes": ["items is truthy"] }
```

Each block is a scope. A variable declared in a block is not visible after its `end`.
